Artificial Intelligence (AI) is a branch of computer science that focuses on building systems capable of performing tasks that normally require human intelligence. These tasks include learning, reasoning, problem-solving, perception, language understanding, and decision-making.

Machine Learning (ML) is a subset of AI in which computers learn patterns from data instead of being explicitly programmed. Deep Learning is a further subset of Machine Learning that uses neural networks with multiple layers to solve complex problems such as image recognition and natural language processing.

Generative AI is a type of AI that can create new content such as text, images, music, code, and videos. Popular Generative AI models include ChatGPT by OpenAI, Gemini by Google, Claude by Anthropic, and Llama by Meta.

Large Language Models (LLMs) are trained on massive amounts of text data and can answer questions, summarize information, translate languages, write code, and assist in many knowledge-based tasks.

Retrieval-Augmented Generation (RAG) combines information retrieval with language models. Instead of relying only on the model's memory, RAG retrieves relevant documents from a knowledge base and provides them as context before generating an answer. This helps reduce hallucinations and improves factual accuracy.

Embeddings are numerical vector representations of text. Similar pieces of text have similar embeddings, allowing semantic search instead of keyword matching. Vector databases such as ChromaDB, Pinecone, FAISS, and Weaviate store these embeddings and perform efficient similarity searches.

Prompt Engineering is the process of designing effective prompts to guide the behavior of language models. Well-designed prompts improve the quality, accuracy, and consistency of AI-generated responses.

LangChain is an open-source framework for building applications powered by Large Language Models. It provides components such as Prompt Templates, Chains, Output Parsers, Document Loaders, Memory, Agents, and Retrieval pipelines.

The main stages of a typical RAG pipeline are:
1. Load documents using a document loader.
2. Split the documents into smaller chunks.
3. Convert each chunk into embeddings.
4. Store the embeddings inside a vector database.
5. Embed the user's query.
6. Retrieve the most relevant chunks.
7. Pass the retrieved context to an LLM.
8. Generate the final answer.

Vector databases do not understand words directly. They compare vectors using similarity metrics such as Cosine Similarity, Euclidean Distance, or Dot Product to identify the most relevant information.

AI systems should be developed responsibly by considering fairness, privacy, transparency, security, and accountability. Human oversight remains important, especially for high-risk applications such as healthcare, finance, and law.
